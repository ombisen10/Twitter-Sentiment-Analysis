🧠 Multinomial Naive Bayes Built From Scratch (Rubric Criterion 3 - 15 Points)

Fully implemented without high-level ML libraries using first mathematical principles and Bayes' theorem.

1. Mathematical Formulations

Bayes' Theorem: P(Y = c | X) = [ P(Y = c) * P(X | Y = c) ] / P(X)
Conditional Independence Assumption: P(X | Y = c) = ∏ P(w_j | Y = c)^(x_j)
Additive Laplace Smoothing (α = 1.0): P(w_j | Y = c) = [ Count(w_j, c) + α ] / [ ∑ Count(w_k, c) + α * |V| ]
Log-Space Computation (Prevents Arithmetic Underflow): log P(Y = c | X) = log P(Y = c) + ∑ x_j * log P(w_j | Y = c) ŷ = argmax_c [ log P(Y = c) + X · (log P_c)^T ]

2. Custom Implementation Snippet (`src/naive_bayes_scratch.py`)

class MultinomialNaiveBayesScratch:
    def __init__(self, alpha=1.0):
        self.alpha = float(alpha)

    def fit(self, X, y):
        # 1. Compute Class Priors in Log Space
        self.classes_, class_counts = np.unique(y, return_counts=True)
        self.class_log_priors_ = np.log(class_counts / len(y))

        # 2. Compute Word Counts per Class
        feature_counts = np.zeros((len(self.classes_), X.shape[1]))
        for idx, c in enumerate(self.classes_):
            feature_counts[idx, :] = np.asarray(X[y == c].sum(axis=0)).ravel()

        # 3. Additive Laplace Smoothing
        smoothed_counts = feature_counts + self.alpha
        smoothed_totals = smoothed_counts.sum(axis=1, keepdims=True)

        # 4. Store Conditional Log Likelihoods
        self.feature_log_prob_ = np.log(smoothed_counts) - np.log(smoothed_totals)
        return self

    def predict(self, X):
        # Joint Log Posterior: X · W^T + Log_Priors
        joint_log_prob = X.dot(self.feature_log_prob_.T) + self.class_log_priors_
        return self.classes_[np.argmax(joint_log_prob, axis=1)]

Machine Learning Practical Mini Project (A.Y. 2025-26)

Topic 18: Classify tweets as positive/negative sentiment using Twitter Sentiment dataset.

1. Problem Statement & Motivation

Twitter sentiment analysis automates the extraction of public opinion, consumer sentiment, and brand perception from unstructured microblog messages. Social media posts pose unique NLP difficulties including colloquialisms, slang, abbreviations, emoticons, and pervasive sarcasm.

2. Preprocessing Strategy

Our custom TweetPreprocessor executes 10 sequential transformations: URL scrubbing, user mention isolation, contraction expansion (e.g. can't → cannot), emoticon conversion (:) → sentimentpositive), negation-preserving stopword elimination (preventing words like not or never from being stripped), and WordNet morphological lemmatization.

3. Custom Naive Bayes vs Scikit-Learn

Our scratch implementation of Multinomial Naive Bayes computes class priors and smoothed feature conditional probabilities in log-space to prevent underflow. Testing confirmed exact parity between our scratch implementation and scikit-learn's optimized library (94.55% accuracy on 1,999 test samples).

4. Error Analysis & Limitations

Diagnostic inspection of misclassified test examples revealed two primary sources of error: Sarcasm (e.g. "Oh wonderful, another four-hour delay!" where positive words inflate the positive prior likelihood), and Subtle Dissatisfaction lacking explicit negative terms. Advanced contextual architectures such as BERTweet or RoBERTa are recommended for resolving complex ironies in production.
