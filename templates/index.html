    03 · Criterion 3 · 15 points

    Naive Bayes, built from first principles

    No sklearn.naive_bayes — just counts, Laplace smoothing (α = 1.0) and log-space arithmetic. File: src/naive_bayes_scratch.py.

    Mathematical formulation

    1. Bayes’ theorem

      P(Y=c | X) = P(Y=c) · P(X | Y=c) / P(X)

    2. Conditional independence

      P(X | Y=c) = ∏ P(wⱼ | Y=c)xⱼ

    3. Laplace smoothing (zero-count guard)

      P(wⱼ|c) = (Count(wⱼ,c) + α) / (Σ Count + α·|V|)

    4. Log-space decision (prevents underflow)

      ŷ = argmaxc [ log P(c) + X · log Pcᵀ ]
    Why log-space? Multiplying thousands of tiny probabilities underflows to zero in float64. Summing logs keeps the argmax identical and numerically stable.

    Reference implementation

    class MultinomialNaiveBayesScratch:
    def __init__(self, alpha=1.0):
        self.alpha = float(alpha)

    def fit(self, X, y):
        # 1. Log priors
        self.classes_, counts = np.unique(y, return_counts=True)
        self.class_log_priors_ = np.log(counts / len(y))
        # 2. Word counts per class
        fc = np.zeros((len(self.classes_), X.shape[1]))
        for i, c in enumerate(self.classes_):
            fc[i, :] = np.asarray(X[y == c].sum(axis=0)).ravel()
        # 3. Laplace smoothing → log-likelihoods
        sm = fc + self.alpha
        self.feature_log_prob_ = np.log(sm) - np.log(sm.sum(axis=1, keepdims=True))
        return self

    def predict(self, X):
        jll = X.dot(self.feature_log_prob_.T) + self.class_log_priors_
        return self.classes_[np.argmax(jll, axis=1)]

    Parity check: predictions and probabilities match MultinomialNB(alpha=1.0) on the full test split.

    Topic 18: Tweet sentiment classification

    Problem · pipeline · scratch proof · error analysis

    1 · Problem & motivation

    Twitter sentiment automates brand monitoring, crisis detection and opinion mining. Tweets are uniquely hard: slang, abbreviations, emoticons, sarcasm and 280-character brevity.

    2 · Preprocessing (10 stages)

    URL / mention stripping → contraction expansion (can't → cannot) → emoticon mapping (:) → sentimentpositive) → hashtag normalisation → punctuation cleansing → negation-preserving stopword filtering (not / never kept) → WordNet lemmatisation → sublinear TF-IDF (1–2 grams).

    3 · Scratch vs sklearn

    Custom Multinomial NB computes log-priors and Laplace-smoothed log-likelihoods, scoring via sparse dot product. Result: exact parity with sklearn (94.55%, N = 1,999).

    4 · Error analysis

    • Sarcasm — “Oh wonderful, another delay!”: positive lexicon, negative intent.
    • Hedged dissatisfaction — “Not exactly the best dinner…”: multi-word understatement fools bag-of-words.
    • Polarity-flipped slang — “That song is sick!”: negative adjective, positive praise.

    Production recommendation: contextual encoders (BERTweet / RoBERTa) for irony and domain slang.
